# Quantum Signal Classifier

An interactive in-browser machine learning playground that demonstrates how logistic regression learns a decision boundary from labeled points.

## Highlights
- Click-to-label dataset creation for two classes.
- Live decision boundary + confidence heatmap rendering.
- Adjustable learning rate and epochs-per-step controls.
- Auto-training mode to watch gradient descent convergence in real time.
- Seeded synthetic dataset generator for fast demos.

## Tech
- HTML5 Canvas
- Vanilla JavaScript (no frameworks)
- Modern CSS layout + visual design

## Run
1. Open `index.html` in any modern browser.
2. Add points or click **Generate Dataset**.
3. Train manually or use **Start Auto-Train**.
